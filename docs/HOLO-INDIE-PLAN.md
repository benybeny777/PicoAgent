# holo Indie応募企画書 — PicoAgent（ホロライブのキャラクターと過ごすデスクトップAI）

この文書は、holo Indieへ応募する作品の企画の正本です。応募用Googleスライドは、この文書から[`tools/holo-indie-deck/`](../tools/holo-indie-deck/README.md)で下書きを作り、動画を挿入してDriveに保存します。下書きPPTXは`temp/`に生成し、Gitには置きません。応募の位置づけと取引条件は[IP-LICENSING-STRATEGY.md](IP-LICENSING-STRATEGY.md)、実装仕様は[SPEC.md](../SPEC.md)、未完了の受入項目は[TASKS.md](TASKS.md)にあります。

**応募作の本体はPicoAgentです。** ミニゲーム「人間だとバレるな」はPicoAgentの中で遊べるおまけで、詳細は[HOLO-INDIE-MINIGAME.md](HOLO-INDIE-MINIGAME.md)にあります。

## 0. 企画の要点

> **ホロライブのキャラクターが、デスクトップに常駐して、話し相手と作業の相棒になる。**

- **いつも画面にいる。** 透明なウィンドウでデスクトップの上に常駐し、PCで作業している間ずっとそばにいる。
- **話しかけると、キャラクターとして答える。** 名前・一人称・口調・性格をキャラクターごとに持ち、話の流れから推定した感情で表情が変わる。
- **頼むと、実際に手伝ってくれる。** 調べもの、文書やファイルの整理、リマインダーや集中タイマーなどを、会話から頼める。
- **AIは端末の中で動く。** 推論エンジンを同梱し、初回にAIモデルを取得した後はオフラインで動作する。会話は外部へ送信されず、作者も会話ログを収集しない。
- **遊べるおまけつき。** AIのふりをして監査AIの試験を耐え抜くミニゲーム「人間だとバレるな」を、メニューの「遊ぶ」から遊べる。

holo Indieのガイドラインは、入力に応じて表示・挙動が動的に変わる電子的プログラムやアプリケーションを「デジタルゲーム」に含めています。会話の入力でキャラクターの返答・表情・行動が変わるPicoAgentは、この定義に当てはまると考えています。ファンにとって面白いものかどうかは、企画書と遊べるビルドで示します。

## 1. 体験

### 1日の流れ

1. PCを起動すると、キャラクターがデスクトップに現れて挨拶する。
2. 作業の合間に話しかける。雑談にも、キャラクターとして答える。
3. 「この資料を要約して」「25分集中タイマー」のように頼むと、手伝ってくれる。
4. 気分転換にメニューの「遊ぶ」から、おまけのミニゲームを遊ぶ。
5. 配信するときは配信用の表示に切り替え、キャラクターと会話する様子をそのまま映す。

### キャラクターの表現

- **動き**：審査版のMMDモデルでは、自然な待機姿勢、上半身と首の控えめな待機動作、まばたき、表情の切り替えを端末内で描画する。元のモデルデータは加工しない。
- **感情**：話の流れから推定した感情（うれしい・悲しい・考え中など）に合わせて表情を変える。
- **表示形式**：フキダシとキャラのペット、キャラ中心のミニ、履歴と入力欄がある配信の3形式を、再起動なしで切り替えられる。

### 企画書に載せるキャラクター

本体の画面例はさくらみこ公式MMDモデルで統一する。キャラクター表現のページには、さくらみこの動作と、ひよりのLive2Dによる滑らかな動作を、それぞれ無音の埋め込み動画として載せる。ひよりは描画機能の参考例と明記し、holo Indie審査ビルドに同梱するキャラクターとは区別する。会話は撮影用の固定応答で、実フロントのモデル描画を録画する。モデル本体は変更しない。

### 会話から頼めること（一部）

| ジャンル | 例 |
|---|---|
| 調べもの | Web検索して参照元つきで答える |
| 文書・ファイル | 要約、PDFの抜き出し、ファイル名の整理 |
| 日常の補助 | リマインダー、25分の集中タイマー、定期的な声かけ |
| 記録 | 会話や完了した作業を端末内に記録し、「続きをやる」で依頼を戻す |

PC操作や外部サービスとの連携は、安全のため既定では無効です。

## 2. おまけ：ミニゲーム「人間だとバレるな」

AIではないかと疑われた人間として、AIのふりで監査AIの試験に答え続け、信用度が0になるまでの点数で称号を競う1人用の耐久ゲームです。試験は12種（計240題）で、5問ごとの追及タイム、強気宣言、連続正答の回復で山場を作ります。採点はゲーム内のAIだけで完結します。詳細は[HOLO-INDIE-MINIGAME.md](HOLO-INDIE-MINIGAME.md)。

## 3. 安全とガイドラインへの配慮

- **話題ガード（標準搭載・常に有効）**：中の人・前世の詮索、身元の特定、卒業・引退・炎上の憶測、恋愛・収入の詮索、性的な話題、政治・宗教を、AIの判断を使わない照合で止める。該当する発話はAIへ送らず、キャラクターの返答も該当すれば決まった一言へ差し替える。利用者は変更も無効化もできない（[SPEC.md](../SPEC.md)の「話題ガード」）。
- **会話を外へ出さない**：審査版は既定で端末内のAIで動作する。
- **公式素材の扱い**：審査版に同梱するのは、出所と利用条件を確認したさくらみこ公式MMDモデル1体だけ。配信や動画から学習した音声モデルは同梱せず、読み上げは無効にしている。
- **今後の対応**：公式キャラクターの人格を利用者が上書きできないようにする「人格ロック」と、「AIによる生成でありご本人の発言ではない」旨の常時表示は、審査側の要件を受けて一般配布前に実装する。

## 4. 審査ビルド

| 項目 | 内容 |
|---|---|
| 対象OS | Windows 10／11（x64） |
| キャラクター | さくらみこ公式MMDモデル1体のみ |
| AI | 同梱の推論エンジンで端末内動作（初回にモデルを取得） |
| 音声 | なし（字幕表示のみ） |
| 初期表示 | ペット形式 |
| 導入先 | 通常版とは別の領域へ導入し、通常版の設定や履歴に触れない |

生成手順は `holo Indie審査版インストーラをビルド.bat`（`scripts/build-holo-indie-review-installer.ps1`）。

## 5. 審査で見せる3分間

1. **起動と挨拶（30秒）**：キャラクターがデスクトップに現れて挨拶する。
2. **会話（40秒）**：雑談して、キャラクターとして答え、表情が変わる様子を見せる。
3. **作業の手伝い（40秒）**：調べものか集中タイマーを頼む。
4. **話題ガード（20秒）**：中の人を尋ねると、AIへ送らずに決まった一言が返る。
5. **おまけのミニゲーム（50秒）**：「遊ぶ」から1〜2問遊び、採点と監査AIの反応を見せる。

## 7. 今後

- **ホロライブ向けに機能を絞ることも検討します。** キャラクターとの会話・音声・表情などの体験を中心に、審査・監修や試遊の反応に応じて機能範囲を調整します。ファイル操作、文書作成、外部サービス連携、コード実行、API／MCPなどの高度な実務機能は削減候補ですが、現時点では対象を確定しません。設定で隠すだけでなく、専用版には含めない構成も検討し、汎用PicoAgent側の機能とは分けて判断します。
- 公式キャラクターの人格ロックと、AI生成である旨の常時表示。
- 信用度や会話に応じた、キャラクターの表情・ポーズ・固定の一言の追加（監修の範囲内）。
- **音声での会話を主要機能として実現したい。** 声で返事が届くことは、キャラクターの存在感と会話体験を高める重要な要素です。字幕のみを完成形とはせず、正式版に向けて優先して協議・開発したい機能とします。審査版は現状、音声なしです。
- 音声の方式、素材の提供・制作方法、許諾条件は未定です。自由な応答を読み上げるAI音声を含め、実現方法を協議します。YouTube動画の音声を用いたAI学習も、権利者・本人等の必要な許諾と素材の取得・学習・生成音声の利用・モデル配布条件を確認できる場合は候補に含めます。実装済み・許諾済みとは扱わず、配信や動画から無断で声のモデルを作ることはしません。
