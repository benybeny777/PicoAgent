# holo Indie応募企画書 — PicoAgent（ホロライブのキャラクターと過ごすデスクトップAI）

この文書は、holo Indieへ応募する作品の企画の正本です。応募用Googleスライドは、この文書から[`tools/holo-indie-deck/`](../tools/holo-indie-deck/README.md)で下書きを作り、動画を挿入してDriveに保存します。下書きPPTXは`temp/`に生成し、Gitには置きません。応募の位置づけと取引条件は[IP-LICENSING-STRATEGY.md](IP-LICENSING-STRATEGY.md)、実装仕様は[SPEC.md](../SPEC.md)、未完了の受入項目は[TASKS.md](TASKS.md)にあります。

**応募作の本体はPicoAgentです。** ミニゲーム「人間だとバレるな」はPicoAgentの中で遊べるおまけで、詳細は[HOLO-INDIE-MINIGAME.md](HOLO-INDIE-MINIGAME.md)にあります。

### 応募で提案する体験

ホロライブのキャラクターと日常的に触れ合いたいファンに向け、PCを開くたびに推しと会い、話題によって返答と表情が変わる体験を提案します。雑談だけでなく調べものやタイマーを頼めるため、毎日立ち上げる理由があります。会話の予想外の反応と、おまけの監査ゲームの講評は、配信でも共有できる見せ場です。

一般的なゲームとは少し異なる常駐型の企画で恐縮ですが、会話によって反応が変わる体験と遊べるおまけを含む作品として応募します。応募資料では「誰が、何を繰り返し楽しむか」を先に示し、動作動画・機能・審査ビルドをその実現性の証拠として示します。審査では、ファンにとって面白いかを遊べるビルドで見ていただき、公式キャラクターの口調・表情・話題、音声の許諾条件と一般配布までに必要な監修範囲を相談したいと考えています。

### 企画の着眼点

配信や動画は、ファンが時間を合わせて「見に行く」推しです。PicoAgentは、PCを開けばそこにいて、作業の合間に話しかけると返事が返ってくる「そばにいる」推しを提案します。反応は話題と感情で毎回変わるため、短い時間でも繰り返し楽しめます。

### 繰り返し遊ばれる3つのループ

- **会話のループ**：話しかけると返答と表情が変わり、次は何を話すか試したくなる。
- **相棒のループ**：調べもの・要約・タイマーなどを頼むと実際に手伝ってくれるため、毎日立ち上げる理由になる。
- **共有のループ**：会話の予想外の反応や、おまけの監査ゲームの講評が配信の見せ場になる。

### 開発の経緯

PicoAgentは、実際にPCで使う人の話し相手と作業の相棒を目指して開発してきました。作るなかで特に手間がかかったのが、キャラクターの見た目や動きを用意することです。一方、キャラクターに愛着を持って日々使えることは、この体験の大きな価値だと感じています。既に魅力あるキャラクターがいるIPコンテンツなら、この強みを生かせると考え、holo Indieへの応募を検討しました。公式キャラクターを使う範囲や表現は、権利者の条件と監修に従って決めます。

## 0. 企画の要点

> **ホロライブのキャラクターが、デスクトップに常駐して、話し相手と作業の相棒になる。**

- **いつも画面にいる。** 透明なウィンドウでデスクトップの上に常駐し、PCで作業している間ずっとそばにいる。
- **話しかけると、キャラクターとして答える。** 名前・一人称・口調・性格をキャラクターごとに持ち、話の流れから推定した感情で表情が変わる。
- **Aivisで自由に話す。** AIが会話に応じて作った返答を、Aivisの音声でその場で話す。審査版の声はさくらみこ本人のものではない。本人の音声を許諾の下で学習・登録すれば、本人の声を再現したAI音声へ差し替えられる。
- **頼むと、実際に手伝ってくれる。** 調べもの、文書やファイルの整理、リマインダーや集中タイマーなどを、会話から頼める。
- **AIは端末の中で動く。** 推論エンジンを同梱し、初回にAIモデルを取得した後はオフラインで動作する。会話は外部へ送信されず、作者も会話ログを収集しない。
- **遊べるおまけつき。** AIのふりをして監査AIの試験を耐え抜くミニゲーム「人間だとバレるな」を、メニューの「遊ぶ」から遊べる。

holo Indieのガイドラインは、入力に応じて表示・挙動が動的に変わる電子的プログラムやアプリケーションを「デジタルゲーム」に含めています。会話の入力でキャラクターの返答・表情・行動が変わるPicoAgentは、この定義に当てはまると考えています。ファンにとって面白いものかどうかは、企画書と遊べるビルドで示します。

## 1. 体験

### 1日の流れ

1. PCを起動すると、キャラクターがデスクトップに現れて挨拶する。
2. 作業の合間に話しかける。雑談にも、キャラクターとして答える。
3. 「この資料を要約して」「25分集中タイマー」のように頼むと、手伝ってくれる。
4. 気分転換にメニューの「遊ぶ」から、おまけのミニゲームを遊ぶ。
5. 配信するときは配信用の表示に切り替え、キャラクターと会話する様子をそのまま映す。

### キャラクターの表現

- **動き**：審査版のMMDモデルでは、自然な待機姿勢、上半身と首の控えめな待機動作、まばたき、表情の切り替えを端末内で描画する。元のモデルデータは加工しない。
- **感情**：話の流れから推定した感情（うれしい・悲しい・考え中など）に合わせて表情を変える。
- **表示形式**：フキダシとキャラのペット、キャラ中心のミニ、履歴と入力欄がある配信の3形式を、再起動なしで切り替えられる。
- **キャラクターの追加**：利用者がMMDやLive2Dなどのモデルを登録できる。アプリは登録するキャラの個数に固定上限を設けない。各モデルの利用条件と端末の保存容量は別途守る。

キャラクター表示は、オリジナルのPNGパラパラ漫画形式、Live2D、MMDに対応する。VRMも以前の対応実績があり、現在使っていない経路を再有効化して対応できる。審査版に同梱するキャラクターは、これらの対応形式の数とは別で、テストとして入れたさくらみこの公式MMDモデル1体である。許可が出れば、他のキャラクターも同梱する。

### 企画書に載せるキャラクター

審査版の主役はさくらみこ。キャラクター表現のページには、さくらみこの動作とAivis音声による会話動画に加え、滑らかなLive2D動作を示すひよりの動画を載せる。ひよりはLive2Dのサンプルキャラで、現行UIで撮影した無音の動作例である。審査版の同梱キャラではないと明記する。会話は撮影用の固定応答で、実フロントのモデル描画を録画する。モデル本体は変更しない。

### 会話から頼めること（一部）

| ジャンル | 例 |
|---|---|
| 調べもの | Web検索して参照元つきで答える |
| 文書・ファイル | 要約、PDFの抜き出し、ファイル名の整理 |
| 日常の補助 | リマインダー、25分の集中タイマー、定期的な声かけ |
| 記録 | 会話や完了した作業を端末内に記録し、「続きをやる」で依頼を戻す |

PC操作や外部サービスとの連携は、安全のため既定では無効です。

PicoAgent本体には、文書処理や外部サービス連携など多くの機能があります。holo Indie向けには、キャラクターとの会話・音声・表情とおまけの遊びを中心に機能を絞る企画です。現在の審査版には実務機能も残っており、専用版での削減範囲は試遊と監修を踏まえて決めます。

## 2. おまけ：ミニゲーム「人間だとバレるな」

AIではないかと疑われた人間として、AIのふりで監査AIの試験に答え続け、信用度が0になるまでの点数で称号を競う1人用の耐久ゲームです。試験は12種（計240題）で、5問ごとの追及タイム、強気宣言、連続正答の回復で山場を作ります。採点はゲーム内のAIだけで完結します。詳細は[HOLO-INDIE-MINIGAME.md](HOLO-INDIE-MINIGAME.md)。

## 3. 安全とガイドラインへの配慮

- **話題ガード（標準搭載・常に有効）**：中の人・前世の詮索、身元の特定、卒業・引退・炎上の憶測、恋愛・収入の詮索、性的な話題、政治・宗教を、AIの判断を使わない照合で止める。該当する発話はAIへ送らず、キャラクターの返答も該当すれば決まった一言へ差し替える。利用者は変更も無効化もできない（[SPEC.md](../SPEC.md)の「話題ガード」）。
- **会話を外へ出さない**：審査版は既定で端末内のAIで動作する。
- **公式素材の扱い**：審査版に同梱するキャラクターモデルは、出所と利用条件を確認したさくらみこ公式MMDモデル1体だけ（テストとしての同梱。許可が出れば他のキャラクターも同梱する）。Aivis本体を同梱し、初回起動時にAivisHub公開モデル「まお」を取得して仮音声で読み上げる。これは本人の声ではない。配信や動画から学習した音声モデルは同梱しない。利用者が登録できるキャラの個数に固定上限はない。
- **今後の対応**：公式キャラクターの人格を利用者が上書きできないようにする「人格ロック」と、「AIによる生成でありご本人の発言ではない」旨の常時表示は、審査側の要件を受けて一般配布前に実装する。

## 4. 審査ビルド

| 項目 | 内容 |
|---|---|
| 対象OS | Windows 10／11（x64） |
| 同梱キャラクター | テストとしてさくらみこ公式MMDモデル1体。許可が出れば他のキャラクターも同梱する。利用者は別のモデルも追加でき、登録数に固定上限はない |
| キャラクター表示形式 | オリジナルPNGパラパラ漫画、Live2D、MMDに対応。VRMも過去の実装を再有効化して対応可能 |
| AI | 同梱の推論エンジンで端末内動作（初回にモデルを取得） |
| 音声 | AIが会話に応じて作った返答をAivisでその場で話す。審査版の声は公開モデルを使用 |
| 初期表示 | 配信形式 |
| 導入先 | 通常版とは別の領域へ導入し、通常版の設定や履歴に触れない |

現在はWindowsのゲーミングPCやMacでの利用を想定し、審査版はWindows向けの端末内で動作するデスクトップアプリです。画面表示と会話・音声などの処理は分離しているため、将来はSaaS型のサービスへ作り変えられます。バックエンドはクラウドにもオンプレミスにも配置できます。サービス提供に必要な認証・認可は別途実装します。

macOS（Apple Silicon）とUbuntu Linux x64にもビルド経路があり、基本機能はある程度動作します。ただし今回提出する審査版はWindows向けです。他OSの配布には実機での機能・見た目の確認と、署名など配布条件の確認が必要です。画面表示と処理を分離した構成により、会話などの中核ロジックを再利用してスマートフォンへ展開できます。スマートフォン向けの画面、OS権限、音声・モデル実行、配布経路は別途実装・検証します。展開時期は未定です。macOS版には取り組む予定で、Linux・スマートフォン・SaaSは勝ち筋や要望があれば検討します。

生成手順は `holo Indie審査版インストーラをビルド.bat`（`scripts/build-holo-indie-review-installer.ps1`）。

## 5. 審査で見せる3分間

1. **起動と挨拶（30秒）**：キャラクターがデスクトップに現れて挨拶する。
2. **会話（40秒）**：雑談して、キャラクターとして答え、表情が変わる様子を見せる。
3. **作業の手伝い（40秒）**：調べものか集中タイマーを頼む。
4. **話題ガード（20秒）**：中の人を尋ねると、AIへ送らずに決まった一言が返る。
5. **おまけのミニゲーム（50秒）**：「遊ぶ」から1〜2問遊び、採点と監査AIの反応を見せる。

## 6. 収益化

PicoAgentはもともとBOOTHやSteamでの販売を目標に開発しており、継続的な開発・運営のため収益化を前提としています。本企画ではホロライブIPの力が非常に大きいため、価格、課金対象、販売方式は貴社の方針・ご指示に従って決めたいと考えています。汎用のフル機能版を別に販売する可能性もありますが、holo Indie採用との両立が難しい場合は別売りを行いません。現時点で具体的な価格や販売方法は確定していません。

### 審査で相談したい許可・監修

- 口調・表情・話題など、キャラクター表現の範囲の監修。
- YouTube等の公開音声、または提供いただく音声を使ったAI学習、生成音声の利用・モデル配布に必要な許可と条件。許可前に本人の声を学習・同梱しない。
- キャラクターモデルの提供。提供が難しい場合は、無償公開されているMMDモデルを審査版・配布版へ同梱する許可と条件。
- 価格・販売方式の方針。収益化は前提としつつ、IPの寄与が大きいため貴社のご指示に従う。汎用フル機能版の別売りが採用条件と両立しない場合は行わない。

- **ホロライブ向けに機能を絞ることも検討します。** キャラクターとの会話・音声・表情などの体験を中心に、審査・監修や試遊の反応に応じて機能範囲を調整します。ファイル操作、文書作成、外部サービス連携、コード実行、API／MCPなどの高度な実務機能は削減候補ですが、現時点では対象を確定しません。設定で隠すだけでなく、専用版には含めない構成も検討し、汎用PicoAgent側の機能とは分けて判断します。
- 公式キャラクターの人格ロックと、AI生成である旨の常時表示。
- 信用度や会話に応じた、キャラクターの表情・ポーズ・固定の一言の追加（監修の範囲内）。
- **Aivisでキャラクターが話す。** 審査版でも、会話に応じてAIが作った返答をAivisの音声でその場で話します。固定台詞だけでなく、自由な会話を声で届けます。必要な許諾を得た本人の音声でモデルを学習し、品質を確認して登録すれば、追加の音声基盤開発を待たず、本人の声を再現したAI音声へ差し替えられます。
- 音声素材の提供・制作方法と許諾条件は未定です。YouTube動画の音声を用いたAI学習も、権利者・本人等の必要な許諾と素材の取得・学習・生成音声の利用・モデル配布条件を確認できる場合は候補に含めます。許諾済みのモデルはまだなく、配信や動画から無断で声のモデルを作ることはしません。
