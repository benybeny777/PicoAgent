# TポーズVRM制作記録

腕と表情を自然に動かせる平面VRMとして、同一Tポーズ原画から17パーツを決定的に抽出します。制作時点で既存Live2D／PicoAgentパーツは再利用していません。

## 入力と拡大

- 原画: `tools/mugi-vrm/source/mugi-tpose-source-v1.png`
- 高解像度化: デスクトップ版Photoshop「ディテールを保持 2.0」のみ
- 作業PSD: `tools/mugi-vrm/source/mugi-tpose-source-v1-photoshop-pd2-2920x4096.psd`
- 寸法: 730×1024から2920×4096

生成AI、ブラウザー、Pillow、ImageMagick、OS APIによる画像拡大は使用しません。

## 分割方針

`tools/mugi-vrm/pipeline/tpose_vrm_layers.py` が頭、胴体、左右腕、左右肩下地、左右脚、白目、虹彩、まつ毛、口、口内を抽出します。肩は同じ原画の丸い下地を腕の背面へ置き、スカート裾は胴体固定の一枚へ含めます。中立目を別下地へ重ねないため、自動モーションを止めても目が二重になりません。

## 現在の判定

約60〜70度まで下げた腕で肩の穴、白縁、二重輪郭がないことを確認済みです。まばたき、左右独立まばたき、視線4方向、5母音、5感情、カスタム4表情は空でないモーフへ接続されています。PicoAgentでは独立した実験キャラとして胸上表示します。
