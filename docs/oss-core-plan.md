# エージェント中核のOSS化準備

## 目的

PicoAgent本体の製品体験を維持したまま、Tauriやキャラクター表示に依存しないエージェント中核を、第三者が再利用・検証できるRustライブラリへ段階的に分離する。

## 現在の境界

`crates/picoagent-core` は内部crateで、PicoAgent本体が実際に利用する。現段階では誤公開を防ぐため `publish = false` とし、ライセンスは決定しない。

含めるもの:

- 正規形メッセージ、ツール呼び出し、使用量の型
- プロバイダに依存しない応答正規化
- UTF-8ストリームなどランタイム非依存の安全処理
- 将来のエージェントループ、キャンセル、実行イベントの抽象

製品側へ残すもの:

- Tauri、ウィンドウ、メニュー、設定画面
- Live2D、THA3、音声、感情、関係性
- 同梱推論エンジンとOS固有処理
- PicoAgent固有の権限方針と商用スキル

## 次の切り出し条件

1. `Config`を直接要求しない読み取り専用の設定インターフェースを定義する。
2. `Provider`と`Tool`の契約からTauri型を排除する。
3. エージェントループの進捗通知をコールバックまたはイベントtraitへ置き換える。
4. PicoAgent本体と最小CLIの2利用者で同じAPIを使い、製品固有の前提が漏れていないか確認する。
5. API安定性、セマンティックバージョニング、ライセンス、脆弱性報告窓口を決めてから公開する。

## 公開判定

- PicoAgent本体のテストに加え、コアcrate単体テストが継続して通る。
- 設計ガードがコアcrateも走査する。
- `tauri`、`PICOAGENT_*`、ファイルシステム、ネットワークへの直接依存がコアに無い。
- 公開APIをPicoAgent自身が最低1回のリリースで利用している。
- ライセンスを利用目的に合わせて決定している。
