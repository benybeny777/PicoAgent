# エンドユーザー使用許諾契約（販売前たたき台）

> この文書は実装検討用のたたき台です。法的助言ではなく、販売者情報・準拠法・Live2D指定文言は未確定です（返金条件は下記8のとおり確定済み）。正式販売前に専門家確認を受け、確定版へ差し替えてください。

## 確定版に必要な条項

1. 契約主体、対象製品、契約成立時点
2. 端末数・利用者数・個人／法人利用の許諾範囲
3. 再配布、転売、解析、回避行為に関する条件
4. 利用者が追加するキャラクター・音声・外部サービスの権利と責任
5. 禁止用途、安全機能を回避した利用の禁止
6. クラウドAI・外部連携・第三者ソフトウェアの扱い
7. アップデート提供期間、旧版利用、サポート範囲
8. 返金・解約・ライセンス停止条件（**返金方針は確定**: デジタル商品につきお客様都合の返品・返金は受け付けない。各販売プラットフォームの返金規定と、法令により返金が必要な場合を除く）
9. 保証の範囲、責任制限、損害賠償上限
10. 契約変更、準拠法、裁判管轄
11. Live2D審査で指定される表示・契約文言

## 製品仕様として先に固定する事項

- 買い切りか、更新権付きか、サブスクリプションか
- Free／Personal／Pro等の機能境界とキャラ追加権限
- オフライン利用とライセンス確認方式
- 1購入あたりの利用可能端末数
- 商用利用、配信利用、法人利用の可否
- サポート期間と対応チャネル

上記が決まるまで `distribution/release.json` の `eulaReviewed` を有効にしません。
