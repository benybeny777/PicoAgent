# サポート運用（販売前ドラフト）

## 利用者へ案内する情報

初期販売の問い合わせでは、PicoAgentのバージョン、Windowsの版、選択中AI、問題が起きた操作、診断タブの状態を確認します。将来macOS版を販売対象へ加えた場合はOS版も確認項目へ追加します。APIキー、トークン、会話全文、個人ファイルは送らないよう案内します。

## 対応レベル案

- インストール・起動・更新不能: 2営業日以内に一次回答
- 購入・ライセンス・二重決済: 2営業日以内に一次回答
- データ消失・セキュリティ疑い: 最優先で受付し、再現操作を止める案内
- 外部サービス側の障害・仕様変更: 状況確認と回避策まで。外部サービス自体は保証対象外
- キャラパック制作相談: 製品不具合と制作代行を分ける

## ユーザーデータ

Windows版のアンインストール時に削除を選ばなければ、設定・履歴・追加キャラ・モデルは残ります。完全削除はアプリ終了後、次のPicoAgent専用領域だけを対象に案内します。macOS版は販売前の実機確認で保存先と削除手順を確定します。

- `%APPDATA%\PicoAgent`
- `%LOCALAPPDATA%\PicoAgent`
- `%APPDATA%\com.picoagent.desktop`
- `%LOCALAPPDATA%\com.picoagent.desktop`

旧版から移行した利用者に限り `com.picoagent.app` / `com.coda.app` が残る場合があります。販売開始前に、バックアップ・復元・ログ書き出しのGUI導線を追加するか判断します。

## 販売前に決めること

- 公開サポートURLと受付メール
- 営業日・対応言語・サポート期間
- 返金窓口と本人確認手順
- 脆弱性報告の非公開窓口
- 障害告知ページと更新履歴の公開場所
