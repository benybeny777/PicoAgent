## 2. PicoAgent について

デスクトップの最前面に常駐するキャラクターが、会話から実務を代行する Windows / macOS 向けアプリケーションです。

| | |
|---|---|
| **AI がローカルで動く** | 推論エンジンを同梱し、初回のみモデルを取得した後はオフラインで動作します。**会話内容は外部に送信されません。** 当方も会話ログを収集しません |
| **74 種の実務機能** | Web 検索、文書作成、画像生成、メール・チャット・カレンダー連携などを、会話の内容から自動で選んで実行します |
| **7 つの表示形式** | デスクトップマスコット、チャット、作業画面のほか、**フル HD の配信用表示**を備えています |
| **キャラクターは差し替え式** | キャラクターパックを追加する構造で、外見・音声・人格・口調をパックごとに定義します |
| **安全側の既定** | ファイル削除は OS のゴミ箱経由のみ、PC 操作・外部連携は既定で無効。認証情報は暗号化して保存します |

現在の版は **v1.0.5 Alpha**（Windows 先行、macOS は v1.0.4）で、無償版を公開しています。実機でのご確認は【配布 URL】からお願いいたします。

## 3. なぜタレント様の IP と相性が良いのか

**接触時間の長さです。**

グッズは棚に置かれ、配信はご視聴いただいている間だけファンの目に入ります。デスクトップ常駐は、**利用者が PC で作業している間ずっと画面にいます。** 1 日数時間 × 数か月という接触を、1,000〜2,000 円台のデジタル商材で作れる形式は他にありません。

加えて、PicoAgent のキャラクターは**眺める対象ではなく、実際に役に立ちます。** 調べもの、文書作成、メールの要約といった日常の作業を手伝うため、「かわいいから起動する」ではなく「使うから起動し、結果として毎日会う」という関係になります。**ファンの生活の中での接触頻度を、実用性で支える設計です。**

デスクトップマスコット市場ではキャラクター DLC の展開が進んでいますが、**VTuber の IP はまだほとんど実装されていません。**

## 4. ご提供形態

ご負担の軽い順に 3 段階をご用意しています。**違いは「声をどうするか」だけで、外見と人格の制作工程は共通です。**

| | 内容 | タレント様のご負担 | 想定価格 |
|---|---|---|---|
| **A. 公式キャラクターパック（初回提案）** | 公式モデルをもとに当方が 2.5D アニメーションを制作。発話は字幕表示 | **なし**（モデルのお貸し出しと監修のみ） | 1,800〜2,200 円 |
| **B. 本人収録ボイス付き** | A に加え、本人収録の定型ボイス（起動時・待機時・作業完了時など）を再生 | 収録のご協力 | 2,980〜3,500 円 |
| **C. 公式音声モデル対応** | **貴社がご用意された公式の音声モデル**をライセンスいただき、AI が生成した応答をその声で読み上げます | 音声モデルのご提供と許諾 | 3,980〜4,800 円 |

**初回は A をご提案します。** タレント様の拘束が発生せず、ご負担が最も軽い形です。

**C についての考え方** — 定型ボイスは台詞が有限なため、利用者はいずれ聞き飽きます。**貴社が公式の音声モデルをお持ちであれば（あるいは今後ご用意のご予定があれば）、その場で生成した応答をタレント様の声でお届けでき、商品価値は大きく変わります。** 当方の製品は音声合成エンジンを統合済みで、キャラクターごとに音声モデルを指定する仕組みがあるため、**公式モデルをお預かりできれば追加開発はほとんど必要ありません。**

なお **C において、当方が既存の音声からタレント様の声を再現するモデルを作ることはありません**（§6）。お預かりするのは、貴社が本人同意のもとでご用意された完成済みの音声モデルと、その利用許諾のみです。

**記念日・イベント連動**（周年、ライブ、新衣装に合わせた期間限定販売）は、A〜C いずれの形態でもお受けできます。

**最低保証（ミニマムギャランティ）は求めません。売上が立たない限り、貴社に損失が発生しない構造です。**

| **契約期間** | 2 年間・自動更新、解約予告 3 か月 |

## 6. 監修と安全性について

**AI がタレント様の名前で発言することのリスクを、最も重要な論点として認識しております。** 次の設計でお応えします。

| 論点 | 当方の対応 |
|---|---|
| **音声** | **当方が、既存の音声からタレント様の声を再現するモデルを作ることはありません。** これは形態 A〜C のいずれでも変わりません。既定（A）は字幕表示のみ。B は貴社にご収録いただいた音声の再生のみ。**C で扱うのは、貴社が本人同意のもとでご用意された公式の音声モデルに限り**、その利用範囲・再配布禁止・契約終了時の停止手順を契約で明記します |
| **人格・口調** | 性格、話し方、一人称、挨拶文、システムプロンプトの全文を**事前にご提出し、書面での承認**をいただきます。公式キャラクターでは**利用者による人格の上書きを禁止**します（人格ロック機能を実装します） |
| **発言内容の制御** | 貴社よりご指定いただく禁止話題・禁止表現について、AI の出力を通過させないフィルタを実装します。モデルの判断任せにしません |
| **AI である旨の表示** | アプリ内に「AI による生成であり、ご本人の発言ではない」旨を常時表示します |
| **会話の秘匿** | 既定のローカル動作では会話が外部に送信されません。**当方は会話ログを一切収集しません。** 外部 AI の利用可否は、公式キャラクターでは貴社にご指定いただけるようにします（既定は無効でのご提案です） |
| **学習への不使用** | ご支給いただいた素材および利用者の会話を、AI モデルの学習に使用しません |
| **表現の範囲** | 性的表現・暴力表現・特定の政治的主張を行わないことを、人格設定とフィルタの双方で担保します |

> **現状のご報告** — 人格ロック機能と発言フィルタは**本提案に合わせて実装する予定の機能であり、現行の公開版には未実装です。** ご承認の見込みが立った段階で最優先に実装し、**監修開始前に実装済みの版でご確認いただきます。**

## 7. お借りする素材と監修の流れ

### お借りしたい素材

**タレント様の正本は Live2D モデルまたは 3D モデルであると理解しております。** どちらでもお受けできます。

| 素材 | 当方での扱い |
|---|---|
| **3D モデル（VRM 等）** | **こちらで表情とポーズをレンダリングし、2.5D パックに起こします。** 公式モデルそのものを描画するわけではないため、**モデルデータが製品に含まれることはありません**（後述） |
| **Live2D モデル** | 同上のレンダリング方式でお受けします。モデルをそのまま動かす方式は、当方の Live2D ライセンス手続きが完了した段階で上位プランとしてご相談させてください |
| 立ち絵（PSD・1 枚絵） | ご支給いただける場合は制作精度が上がります。**必須ではありません** |
| キャラクター設定資料 | 口調、一人称、呼称、NG 事項。人格設定の起案に使用します |
| 音声（形態 B・C の場合） | B は音声ファイルと台本（台本は当方から原案をご提出）。C は公式の音声モデル |

**当方で制作するもの** — 表情差分（通常・半目・閉じ目・開口・閉口・左右視線・喜び・悲しみ）、まばたきと口の動きのアニメーション、通常表示用および配信表示用の構図、人格設定の原案。

### お預かりしたモデルの取り扱い

**モデルデータのお貸し出しにご懸念があることは承知しております。** 次の条件を当方からお約束します。

| | |
|---|---|
| **製品に同梱しません** | 出荷物はレンダリング済みの 2.5D パックです。**Live2D / 3D の元モデルは利用者の端末に一切渡りません。** 構造上、製品からモデルデータを取り出すことはできません |
| **秘密保持契約** | 貸与期間、利用範囲、作業完了後の破棄と報告を定めます |
| **作業環境の限定** | 汎用のクラウドサービスへ素材をアップロードしません |
| **返却・破棄** | 制作完了後、ご指定の期日までに破棄し、ご報告します |

| 1 | 素材のご支給、仕様のすり合わせ | 2 週 |

**修正は各段階 2 回までを想定しています**（貴社の監修工数を予測可能にするためです。回数・期日はご相談に応じます）。
