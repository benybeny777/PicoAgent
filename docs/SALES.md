# PicoAgent 販売戦略（競合ポジション調整版）

この文書は「PicoAgent をどう売るか」を、実在の競合と価格アンカーに合わせて調整した検討メモです。実装ルールではありません（ルール正本は [AGENTS.md](../AGENTS.md)）。数字は 2026 年 8 月時点の公開情報に基づく想定で、契約前には必ず一次情報を確認してください。

---

## 1. 何を売るのか（現状の資産）

| 資産 | 内容 | 競合優位性 |
|---|---|---|
| ローカル完結の推論 | llama-server 同梱・初回だけ GGUF を DL・以後オフライン | Ollama も Node も不要。導入は 1 バイナリ |
| 実務スキル 67 種 | Gmail / Slack / Google Workspace / GitHub / Notion / PDF / Office / 議事録 / スケジューラ / コード実行 | 「かわいいだけ」の競合が持っていない層 |
| キャラクター体験 | 透明ウィンドウ常駐・Live2D・読み上げ・ふれあい・関係性の記録 | 「実務だけ」の競合が持っていない層 |
| 安全設計 | 許可ルート・物理削除禁止・シークレット暗号化・設計ガード群 | 法人へ売るときの唯一の説得材料 |
| ローカル API / MCP | 外部ツールから叩ける・MCP サーバ／クライアント両対応 | 開発者層の入り口 |

**一行の売り文句（案）**
> クラウドに送らずに、実務までやる相棒。デスクトップに住む AI エージェント。

---

## 2. 競合マップ

PicoAgent は 1 つの市場ではなく、4 つの隣接市場の**交差点**にいます。それぞれ「勝てる点」と「勝てない点」が違うので、価格も訴求もその交差点に合わせて調整する必要があります。

| 群 | 代表 | 価格 | 強み | PicoAgent が勝てる点 | 勝てない点 |
|---|---|---|---|---|---|
| **A. デスクトップマスコット** | Desktop Mate（Steam 無料 + キャラ DLC 2,200 円）、Shimeji、VTube Studio | 無料〜2,200 円/キャラ | 圧倒的な認知・公式 IP（初音ミク等）・3D 品質 | 実務ができる（この群は会話も作業もほぼ無い） | キャラ IP の魅力・3D 表現・既存ユーザー数 |
| **B. OSS AI コンパニオン** | Open-LLM-VTuber（GitHub 12k★）、AITuberKit | 無料 | ローカル完結・Live2D・音声対話・熱心なコミュニティ | インストーラ一発・実務スキル数・安全境界・法人適性 | 価格（無料）・カスタマイズ自由度・OSS の信頼感 |
| **C. 汎用 AI アシスタント** | ChatGPT / Claude / Copilot / Perplexity | 月 20 ドル前後 | モデル品質・ブランド・エコシステム | ローカル完結（外部送信なし）・常駐キャラ・買い切り可 | 生の回答品質。ここは正面から戦わない |
| **D. ローカル LLM ツール** | LM Studio、Ollama、Open WebUI | 無料 | 開発者に浸透済み | 非開発者がそのまま使える体験・スキル・キャラ | 無料・モデル運用の柔軟性 |
| **E. ハード型相棒** | Gatebox、卓上 AI ロボット | 数万〜十数万円 | 存在感・話題性 | 価格・PC 上で実務まで届く | 物理的な「居る感」 |

### 空白地帯

- A は**かわいいが働かない**。B は**働きかけるが導入が難しく、スキルが薄い**。C は**働くがクラウドに出るしキャラがいない**。D は**開発者専用**。
- **「キャラが常駐して、ローカルで、実務スキルまで持ち、インストーラ一発」はどこも埋めていません。** ここが PicoAgent の唯一のポジションです。訴求は「かわいい AI」ではなく **「働く相棒」** に寄せ、かわいさは差別化ではなく**継続利用の理由**として扱います。

### 正直な弱点（価格と順序に直結する）

1. **ローカルモデルの実務品質** — Gemma 4 系 small/balanced で 67 スキルを安定に回せるかが商品価値の上限。クラウド鍵持ち込み前提の訴求に逃げると C との直接比較になり負けます。
2. **キャラ IP がまだ弱い** — A の主戦場。同梱の Live2D サンプルは再配布不可（後述）。
3. **署名・自動更新が未設定** — Windows で「不明な発行元」警告が出る状態では有料販売は成立しません。
4. **サポート体制ゼロ** — 法人価格を取るなら応答義務が発生します。

## 3. 販売前に必ず片付けるブロッカー

有償化はここが終わるまで開始できません。**順序を間違えると返金・差止のリスクが直撃します。**

| # | 項目 | 内容 | 対応 |
|---|---|---|---|
| B1 | **リポジトリに LICENSE が無い** | 現状は全権利留保。OSS でも商用ライセンスでもない宙ぶらりん | 後述のオープンコア方針に沿って `LICENSE` と `LICENSE-COMMERCIAL` を置く |
| B2 | **Live2D** | Cubism Core は Live2D Proprietary Software License。**年商 1,000 万円以上の事業者は Cubism SDK リリースライセンス（出版許諾契約）が必要**。同梱サンプル（ひより／Haru／Epsilon）は Free Material License で、有償製品への同梱・再配布は不可と考えるべき | 自社 IP の Live2D モデルを 1〜2 体用意。売上規模に応じて Live2D 社と契約 |
| B3 | **同梱 OSS のライセンス** | ffmpeg / ImageMagick / qpdf / poppler は GPL 系を含み、同梱配布には条件が付く。llama.cpp・whisper.cpp は MIT | 「同梱」ではなく**ユーザー環境での取得**に寄せるか、LGPL/許諾済みビルドへ差し替え。ライセンス表記画面を用意 |
| B4 | **モデルの利用規約** | Gemma / Qwen / Llama は各々の利用規約。自動 DL は PicoAgent が配布しているわけではないが、同意表示は要る | 初回 DL 時に規約同意 UI を挟む |
| B5 | **コード署名・自動更新** | Authenticode 証明書（年 3〜10 万円）と `tauri-plugin-updater` | 有償版の必須要件。証明書取得はリードタイムがあるので最初に着手 |
| B6 | **特定商取引法表記・返金規定** | 日本国内で有償販売するなら必須 | 販売ページに設置 |

## 4. 価格設計（競合アンカーに合わせて調整）

### 前提となるアンカー

- Desktop Mate のキャラ DLC = **2,200 円** → 日本のデスクトップマスコット層が「キャラに払う額」の相場。
- ChatGPT / Claude = **月 20 ドル（年 約 36,000 円）** → 「AI に払う額」の上限アンカー。
- OSS 群（Open-LLM-VTuber / AITuberKit / Ollama）= **無料** → 下限アンカー。無料と同じ土俵に立たない設計が必要。

### 推奨: オープンコア × 買い切り

**PicoAgent はユーザーの API 鍵かローカルモデルで動くため、事業者側に推論の変動費が発生しません。** これは C 群に対する最大の武器で、**「月額ではなく買い切り」**という提示がそのまま差別化になります。逆に月額にすると、月 20 ドルの ChatGPT と品質で比較され負けます。

| プラン | 価格 | 含むもの | 狙い |
|---|---|---|---|
| **Free**（OSS コア） | 0 円 | 本体・ローカルモデル・基本スキル（時刻・天気・検索・ファイル・PDF 等）・キャラ 1 体 | B/D 群と同じ土俵で認知を取る。GitHub での星がそのまま販売動線 |
| **Pro（買い切り）** | **4,800 円**（1 年間のアップデート込み、以後も使い続けられる JetBrains 型） | 外部連携スキル（Gmail / Slack / Google Workspace / Notion / GitHub 等）、スーパーエージェント、スケジューラ、ローカル API / MCP サーバ、音声、優先ビルド | ChatGPT 3 か月分未満、という言い方が効く価格帯 |
| **キャラパック** | **1,800〜2,200 円/体** | 自社 IP の Live2D＋音声＋人格 | Desktop Mate の DLC 価格に完全に合わせる。比較されたときに割高に見えない |
| **Business** | **年 18,000 円/席**（5 席〜） | Pro 全機能＋ポリシー配布（許可ルート／禁止スキルの一括設定）、監査ログ、優先サポート、社内モデル指定 | ChatGPT Plus の約半額。「置き換え」ではなく「機密作業用に追加する」枠を狙う |

**なぜ Pro を 4,800 円にするか** — 3,000 円未満は「マスコットアプリ」に見え、実務ツールとして信用されません。9,800 円を超えると「AI に 2 年分前払い」と受け取られます。日本の個人向け買い切りソフトで最も摩擦が小さいのは 3,000〜6,000 円帯で、その中で「ChatGPT 2 か月分」と言い切れる 4,800 円が説明しやすい位置です。

**セール設計** — Steam を使うなら初週 20% / 大型セール 30〜40% までに留め、恒常 50% 引きにはしない（法人価格の根拠が壊れるため）。

## 5. 販路（優先順）

| 順 | 販路 | 手数料 | 何を売るか | 理由 |
|---|---|---|---|---|
| 1 | **自社サイト + Stripe / Lemon Squeezy** | 3〜5% | Pro・Business | 粗利最大。法人請求書・見積に対応できるのはここだけ。Business は必ずここ |
| 2 | **GitHub（Free コア）** | 0 | 無料版 | 販売ではなく獲得チャネル。README の完成度は既に競合以上で、そのまま武器になる |
| 3 | **BOOTH / DLsite** | 5〜10% | キャラパック | 日本のキャラ購買層が既にいる。決済とファン文化の相性が良い |
| 4 | **Steam** | 30% | Free 本体 + キャラ DLC | Desktop Mate の隣に並べる価値は大きいが、手数料 30% と審査・返金規定があるため**キャラ販売専用**と割り切る。実務機能の主販路にはしない |

**Microsoft Store は当面見送り** — 配信の制約（同梱バイナリ・子プロセス起動）が PicoAgent の構造と噛み合いません。

## 6. 実行順序

**Phase 0 — 売れる状態にする（〜2 か月）**
1. B1〜B6 のブロッカー処理（証明書取得を最初に着手）。
2. 自社 IP キャラ 1 体（Live2D＋声＋人格）を用意。Free 版に同梱する「顔」になる。
3. Free / Pro のスキル境界を実装（`config` のライセンス判定 1 箇所で切り替えられる形にする）。

**Phase 1 — 無料で取る（2〜4 か月）**
4. Free 版を GitHub / Steam / X で公開。KPI は DL 数ではなく **7 日継続率**（マスコット系は初日で消される）。
5. 「ローカルで動く AI が Gmail を要約して Slack に投げる」動画を 1 本。A・B・D いずれの層にも刺さる唯一の見せ方。
6. Discord でユーザーの実利用ログ（どのスキルが使われたか）を定性収集。Pro の同梱スキルはここで決める。

**Phase 2 — 有償化（4〜6 か月）**
7. Pro 販売開始。初期購入者に恒久ディスカウント（早期支援者価格 3,800 円）。
8. キャラパック 1 本目を BOOTH / Steam DLC で同時投入。Pro とキャラでユーザー層が分かれるので共食いしません。

**Phase 3 — 法人（6 か月〜）**
9. 「機密文書をクラウドに出せない部署の AI」として Business 版。刺さるのは士業・医療・自治体・製造の設計部門。
10. 監査ログとポリシー配布が無いと商談が進まないので、Phase 2 中に着手しておく。

## 7. 競合が動いたときの備え

| 想定 | 起きること | 打ち手 |
|---|---|---|
| **Desktop Mate が AI 会話を載せる** | A 群の 3 万人規模のユーザーがそのまま会話体験へ移る | 会話では戦わない。**実務スキルと安全境界**へ寄せる。Desktop Mate は OS 操作権限を取りに行きにくい（IP 提供元の制約）ので、そこが堀 |
| **Open-LLM-VTuber がスキルを増やす** | Free 版の優位が消える | 堀は「インストーラ一発」と「設計ガードに支えられた安全性」。OSS が最も追いつきにくいのは**壊れない**こと |
| **OS 標準 AI（Copilot 等）が常駐化** | C 群が無料で全 PC に載る | ローカル完結と**キャラクターへの愛着**が残る。関係性の記録・ふれあいは、機能ではなく乗り換えコストとして効く |
| **クラウド API の値下がり** | ローカル完結の価値が相対的に下がる | 価値の軸を「安い」から「**出さない**」へ固定する。法人向け訴求は最初からこちら |

---

## 8. 決めるべきこと

1. **ライセンスモデル** — 推奨はオープンコア（コアは AGPL または独自ソースアベイラブル、Pro スキルは非公開）。全部 OSS にすると Pro が成立せず、全部クローズドにすると B/D 群からの獲得動線を失います。
2. **キャラ IP への投資額** — Live2D モデル 1 体の外注は 15〜40 万円程度。ここをケチると A 群と並んだときに選ばれません。Phase 0 の最大の支出です。
3. **法人へ行くかどうか** — 行くなら監査ログ・ポリシー配布・サポート窓口が必要で、開発リソースの配分が変わります。個人向けだけなら Phase 3 を丸ごと落とせます。
