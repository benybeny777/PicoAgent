# PicoAgent Distribution

PicoAgentの公開ダウンロード、最新版情報 `latest.json`、サポート、プライバシーポリシー、利用条件を提供する配布専用リポジトリです。ソースコードと第三者ソフトウェアは含みません。

`latest.json` のOS別インストーラ情報は、Releaseへ実ファイルを公開してサイズとSHA-256を照合してから更新します。空欄のプラットフォームはアプリ内アップデート準備中として扱われます。

`index.html` は販売用ランディングページです。`assets/` の画面画像は本体リポジトリの `docs/images/` にある実画面から選び、配布サイトだけで表示できるよう複製しています。完成済み2Dの「むぎ」と、Live2D表示例の「ひより」はアニメーションWebPで動作を見せます。ひよりは表示例であり、販売版へモデル素材を同梱しません。価格・販売先・対応OSを変える場合は、公開前に `docs/SALES.md` と `distribution/release.json` へ整合させます。

ローカル確認は `index.html` を直接開くか、このフォルダを任意の静的HTTPサーバーで配信します。HTTPサーバーを使った場合は確認後に終了してください。

## 公開前の確認

1. `PicoAgent-Distribution` のReleaseに実インストーラがあり、`latest.json` のURL・サイズ・SHA-256が一致するまでは、LPの取得ボタンを「準備中」のままにします。
2. このフォルダ全体を公開配布リポジトリのルートへ同期します。HTMLだけでなく `assets/`、サポート、規約、プライバシー、`latest.json` を同じ版に揃えます。
3. GitHub Pagesのビルド完了後、PC・スマートフォン表示、アニメーション、クレジット、全リンク、実ダウンロードを公開URLで再確認します。
4. 実インストーラ公開後にだけ、準備中表示を正規のGitHub Releasesへのリンクへ変更します。
