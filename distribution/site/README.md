# PicoAgent Distribution

PicoAgentの公開ダウンロード、最新版情報 `latest.json`、サポート、プライバシーポリシー、利用条件を提供する配布専用リポジトリです。ソースコードと第三者ソフトウェアは含みません。

`latest.json` のOS別インストーラ情報は、Releaseへ実ファイルを公開してサイズとSHA-256を照合してから更新します。空欄のプラットフォームはアプリ内アップデート準備中として扱われます。

`index.html` は販売用ランディングページです。`assets/` の画面画像は本体リポジトリの `docs/images/` にある実画面から選び、配布サイトだけで表示できるよう複製しています。完成済み2Dの「むぎ」と、Live2D表示例の「ひより」はアニメーションWebPで動作を見せ、制作中の `mugi-live2d` は掲載しません。ひよりは表示例であり、販売版へモデル素材を同梱しません。価格・販売先・対応OSを変える場合は、公開前に `docs/SALES.md` と `distribution/release.json` へ整合させます。

ローカル確認は `index.html` を直接開くか、このフォルダを任意の静的HTTPサーバーで配信します。HTTPサーバーを使った場合は確認後に終了してください。
