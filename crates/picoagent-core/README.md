# picoagent-core

PicoAgentから、Tauri・OS・キャラクター・製品設定に依存しない処理を段階的に切り出す内部crateです。

PicoAgent製品内だけで使う非公開crateです。外部配布や別リポジトリへの切り出しは行わず、`publish = false`を維持します。

現在含むもの:

- プロバイダ間で共有する正規形メッセージ
- ツール呼び出しとトークン使用量の型
- コネクタ設定項目の型
- reasoningブロックの除去
- UTF-8文字列の安全な切り詰めと逐次デコード
- 読込器へ渡されたデータのSHA-256計算（ファイルの開閉は呼出元）
- Whisperの固定配布情報とMacソースビルドの引数計画

最小RustはSHA-256依存に必要な1.85です。本体とxtaskは従来どおり1.88を使います。

このcrateから `tauri`、PicoAgentの設定キー、ファイルシステム、ネットワーク、特定プロバイダを参照しないことを境界とします。
