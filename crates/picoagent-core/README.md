# picoagent-core

PicoAgentから、Tauri・OS・キャラクター・製品設定に依存しない処理を段階的に切り出す内部crateです。

現時点では公開準備中のため `publish = false` とし、ライセンスも未確定です。PicoAgent本体がこのcrateを実際に利用し、APIと責務の境界が安定してから別リポジトリへの切り出しとOSS公開を判断します。

現在含むもの:

- プロバイダ間で共有する正規形メッセージ
- ツール呼び出しとトークン使用量の型
- コネクタ設定項目の型
- reasoningブロックの除去
- UTF-8文字列の安全な切り詰めと逐次デコード

このcrateから `tauri`、PicoAgentの設定キー、ファイルシステム、ネットワーク、特定プロバイダを参照しないことを境界とします。
