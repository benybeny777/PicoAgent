# Windowsジョブ開始

この`SKILL.md`の2階層上を`<plugin-root>`とする。

具体的な実行ファイル、引数、作業ディレクトリを確定してから、直接argvで1回だけ開始する。

```powershell
pwsh -NoProfile -File "<plugin-root>/scripts/job.ps1" start --name "<表示名>" --cwd "<作業ディレクトリ>" --estimate-minutes <推定分> --notify-interval-minutes 10 --json -- <実行ファイル> <引数...>
```

- 60秒を超える可能性がある有限処理に使う。対話入力、常駐サーバー、watcher、既にdetachするランチャーには使わない。
- 秘密値をargvへ含めない。記録本体はDPAPIで保護されるが、子プロセスのコマンドラインはOSから見える。
- 修復、移行、破壊的変換には`--critical`を付ける。
- 過去の実測、処理量、回線速度、テスト数から推定時間を逆算し、`--estimate-minutes`を必ず付ける。根拠が弱い場合は幅の上限寄りを採用し、利用者へ概算と伝える。
- 実行中は既定10分ごとに経過時間と推定残り時間を通知し、見積り超過時は更新した目安を示す。利用者が別間隔を指定した場合だけ`--notify-interval-minutes`を変える。通知不要の明示指示がある場合だけ`--no-notify`を使う。
- 成功後はジョブIDと所要目安に加えて、`画面上は止まって見えますが、バックグラウンドで動作中です。状況はいつでも確認できます。`と明示する。そのターンでは状態確認、待機、ログ確認を行わない。
